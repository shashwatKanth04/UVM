# UVM Field Automation and Printer Policy Assignments

This repository contains SystemVerilog and UVM source files covering 12 field automation and printer policy exercises, focusing on UVM field automation macros (`uvm_field_int`), object utils begin/end registration, printer policies (table, tree, line printers), bit/decimal/hex formatting, and visibility control (`UVM_NOPRINT`) based on **UVM Field Automation and Printer Policy Assignments**[cite: 7].

---

## 📂 Lab Exercises Overview

| Exercise # | Topic / Concept | Description |
| :--- | :--- | :--- |
| **1** | Observe the Printed Output | Compile base code and analyze output and visibility impact of `UVM_NOPRINT` on field `a`[cite: 7]. |
| **2** | Enable Printing of Field `a` | Remove `UVM_NOPRINT` and compare simulation output before and after modification[cite: 7]. |
| **3** | Binary Printing | Configure field registration using `UVM_BIN` to display fields in binary format with leading zeros[cite: 7]. |
| **4** | Decimal Printing | Format and print both fields in decimal representation using `UVM_DEC`[cite: 7]. |
| **5** | Hexadecimal Printing | Display both fields in hexadecimal format (`UVM_HEX`) and evaluate compactness[cite: 7]. |
| **6** | Mixed Formatting | Apply field-specific formats (`a` in binary, `b` in hexadecimal)[cite: 7]. |
| **7** | Add a New Field | Declare and register a new 16-bit random `data` field printed in hexadecimal[cite: 7]. |
| **8** | Compare Printer Policies | Compare object outputs using table (`uvm_default_table_printer`), tree (`uvm_default_tree_printer`), and line printers[cite: 7]. |
| **9** | Print Multiple Objects | Create multiple instances (`o1`, `o2`, `o3`), randomize, and print via table printer[cite: 7]. |
| **10** | Selective Field Printing | Hide field `b` using `UVM_NOPRINT` and verify only field `a` prints[cite: 7]. |
| **11** | Packet Class | Create a packet class with `addr` (HEX), `data` (DEC), and `write` (BIN) fields[cite: 7]. |
| **12** | Analyze Field Automation | Comment out field macros and examine why UVM automated printing fails without them[cite: 7]. |

## 🚀 Getting Started

### Prerequisites
A SystemVerilog-compatible simulator with UVM library support (such as ModelSim, Questa, VCS, or EDA Playground) is required to compile and execute these exercises[cite: 7].

### Compilation & Simulation
1. Compile the UVM package along with your target exercise file (`+incdir+$UVM_HOME/src $UVM_HOME/src/uvm_pkg.sv`)[cite: 7].
2. Run the simulation to view formatted ASCII tables, trees, and line printer outputs generated by UVM field automation[cite: 7].
